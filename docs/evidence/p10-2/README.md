## 기준선 차이 분류 (1회차)

**바뀐 값:** 카메라에서 나오는 값이다. `distance`, `position`, `target`, `azimuth`, `polar`, `fillPercent`, `screenPx`, `centerOffsetPx`, `touchPx`, `mineCells`, `backPoseMoved`.

**새 필드:** `widthPercent`, `historyPosition`, `areas`.

**의도한 변화:**

- `flows.tireList`: P1-9 수정.
- `crossesBody`: 타이어 전환이 `false`가 됨.
- `flows.emptyTouch.none`: 전조등이 더 가까워져 순수 배경이 없어진 화면 3건.

**변화 없음:** 상태 전이(`state`, `backTo`), 3D 선택 성공 여부(`selected`), 뒤로 가기 결과, 전체 뷰 값, QR·모바일 단계, 이름.

## 상자 안 프레임으로 잡힌 이동

`battery-12v>washer`, `washer>rear-right-result`가 기준선에 `true`로 남아 있다. 근접 시점이 열린 보닛 위에 있어 근사 상자(높이 1.45m) 안에서 시작하거나 끝나기 때문이다. 경로는 끝점 1m 이내만 허용한다. 근사 상자의 한계로 판단하지만, 근거는 경로 규칙과 `washer>rear-right-result` 캡처 1장이다. 전체 프레임을 눈으로 확인하지는 않았으므로 이 두 이동이 차체를 전혀 스치지 않는다고 주장하지 않는다.

## 개발 중 수정 기록

- **끝점 오차:** 새 기준 수치에서 `both ends are exact` 테스트가 실패했다. 직선 경로의 부동소수 오차였고, 테스트가 아닌 코드를 고쳤다.
- **허용 범위:** 측정 후에 넓히지 않았다. `UNDERBODY` 범위는 계획에 없어 구현 전에 정했다.
