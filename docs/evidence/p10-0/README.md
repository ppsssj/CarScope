## 개발 중 수정 기록

- **기준 파일 위치:** `docs/evidence`는 README만 Git에 포함되어 기준 파일이 커밋되지 않을 뻔했다. `tools/three-poc/test/`로 옮겼다.
- **프레임 수 제외:** 실행 속도에 따라 달라져 기준선에는 전환별 차체 통과 여부만 남겼다.
- **첫 변이 시도 실패:** PowerShell 스크립트의 한글 인코딩 오류로 실행되지 않았다. 제품 파일 변경은 없었고 Node로 다시 실행했다.
