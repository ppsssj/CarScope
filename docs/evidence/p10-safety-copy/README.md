# 3D 워셔액 안내 안전 문구 증거 인덱스

3D 워셔액 안내가 캡 개방과 직접 보충을 안내해, 만지지 않고 살펴보라는 모바일 점검(P11)과 달랐다. 3D 안내를 비접촉 육안 확인으로 바꿨다. 전조등 이름은 짧게 유지하고 외관만 점검한다는 뜻은 설명 문구로 전달한다.

기준 main `c4205b8`, Windows 10, Node 22.16.0, 실제 참조 GLB, headless Chrome 157.0.8103.38. 원본은 `C:/CarScope-External/p10/p10-safety-copy/`에 있다.

| 범위 | 판정 |
|---|---|
| 데스크톱 Chrome, 실제 GLB 페이지 | 실행 |
| AVD, Android WebView, 실제 터치, 스마트폰, 운영 서버 | **NOT_RUN** |

## 문구 변경

| 항목 | 이전 | 이후 |
|---|---|---|
| 확인 방법 | `캡을 열어 워셔액 양을 확인합니다` | `겉으로 보이는 모습만 눈으로 확인합니다` |
| 부족할 때 | `워셔액을 보충하고 캡을 닫습니다` | `사용설명서나 제조사 서비스 안내를 따르세요` |
| 주의 | 없음 | `부품을 만지거나 캡·덮개를 열지 마세요. 직접 보충하지 마세요.` |
| 준비 | `평탄한 곳에 정차하고 차량 전원을 끕니다` | 주차 브레이크, 충전 여부, 보닛 고정, 냉각 확인까지 (모바일 문구와 같은 내용) |
| 설명서 링크 | 유지 | 유지. `설명서의 보충 절차는 이 점검에 포함되지 않습니다.` 추가 |
| 전조등 상세·결과 | 없음 | `꺼져 있는 전조등의 겉모습만 눈으로 확인합니다. 켜서 시험하거나 만지거나 분해하지 마세요.` |

## 넘기는 사항

- **P11 `index.html:104`:** `위치가 확실하지 않으면 캡을 열지 마세요.`는 확실하면 열어도 된다고 읽힌다. 모바일 파일이라 수정하지 않았다.
- **모바일·Native 전조등 이름:** `왼쪽 하향등 외관`을 `왼쪽 하향등`으로 바꾸는 작업은 P11 병합 후 별도다.
- **`service-components.mjs`의 `WASHER_GUIDANCE`:** `부족하면 ... 워셔액을 사용하세요`가 남아 있다. 저장소에서 화면에 표시하는 코드를 찾지 못해 형상 모듈을 건드리지 않았다.
