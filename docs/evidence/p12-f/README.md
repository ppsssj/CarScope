## CI 실패 기록

| 커밋 | run | 결과 | 내용 |
|---|---|---|---|
| `20bfc27` | 42376500552 1차 | **FAIL** | Windows, `AR-01 Edge browser regression`, `part-guide-browser.mjs`의 첫 `page.goto`가 15초 안에 `load`에 도달하지 못함 |

- **원인은 미확정이다.** 당시 시험에 네트워크 진단이 없었다. 이번 PR은 이 시험과 그 페이지가 불러오는 파일을 바꾸지 않았고, 플래그가 꺼진 페이지는 탐지 모듈을 불러오지 않는다. 그래도 무관하다고 증명한 것은 아니다.
- **P12-E 페이지 시작 실패와 증상이 다르다.** 그때는 `load` 후 모듈이 실패했다. 이번에는 `load` 자체가 오지 않았다.
- **참고 수치:** P12-E 프로브에서 브라우저의 첫 페이지는 시작이 더 느렸다(Edge 중앙값 486ms, 이후 157ms). 그러나 최대 7,260ms였고, `goto` 실패는 13,824회 중 0건이었다(당시 제한은 30초). 15초를 넘긴 사례는 재현되지 않았으므로 원인으로 단정하지 않는다.
- **조치:** 시간 제한은 그대로 두고, 이 시험의 시작 실패가 대기·실패 요청을 경로만으로 남기게 했다. 초대값이 오류 메시지에 들어가는 문제도 함께 없앴다. 로컬 시험 세션의 값이라 실제 위험은 없었다.
