# P12-A3 설명용 그림을 최종 안내로 확정

**결정(사용자, 2026-11-07):** 실제 사진을 추가하지 않고 SVG 설명용 그림을 부품 안내의 최종 기본 방식으로 쓴다. 결과는 [증거 인덱스](evidence/p12-a3/README.md)에 있다.

## 변경

| 항목 | 이전 | 이후 |
|---|---|---|
| `photoStatus` (19개) | `PHOTO_NEEDED` | `SCHEMATIC_ONLY` |
| 그림마다 붙던 배지, 안내, 출처 줄 | `설명용 그림` 배지, `실제 사진이 아니에요.`, `출처: …` | 삭제. 그림별 설명만 남김 |
| 확대 화면 | 그림별 설명 + 안내 | 그림별 설명만 |
| 안내 하단 | 없음 | `설명용 그림이며 실제 차량과 위치·형태가 다를 수 있습니다.` **한 번** |
| 안내 맨 위의 카드 | `아직 실제 사진이 없어 설명용 그림으로 보여 드려요.` | 삭제 |
| 그림이 하나도 없을 때 | `아직 준비된 사진이나 그림이 없어요…` | `아직 준비된 그림이 없어요…` |

적용 범위 문구는 그대로다. 그림 파일 안의 `설명용 그림`, `참고 배치 예시` 글자는 SVG의 일부라 유지된다.

## 변경하지 않은 것

- SVG 38장과 생성기. 대체 텍스트에 사진 언급이 없어 그림 파일이 바뀌지 않는다.
- 확대·닫기, 이미지 실패 대체, 접힌 상태에서 요청 없음.
- 안내 데이터의 나머지, `imageSource`, `licenseStatus`, `partId`, `taskId`, 정보 페이지. 출처와 라이선스는 화면에서만 빠지고 데이터와 이 문서 체계에 남는다.
- QR, 인증, 세션, 결과 계약, WebXR, 점검 상태 머신, DB, Render.

## 남겨 둔 것

**사진 표시 규칙:** `IMAGE_KIND.PHOTO`와 차종·출처·권리 검사는 지우지 않았다. 실제 사진을 쓰게 되면 그 사진에는 차종과 출처 표시가 함께 나온다. 지금은 어떤 안내도 쓰지 않으므로 화면에 나타나지 않고, 사진이 없으면 필요 없는 코드다. 나중에 결정이 바뀔 때 잘못된 사진이 들어가는 것을 막는다. 지우려면 별도 정리 작업으로 한다.

**이전 문서:** [P12-A](p12-a-part-photo-guide.md)의 `필요한 사진`은 당시 기록이다. 지난 실행의 증거 인덱스는 고치지 않는다.

## 알려진 제약

그림은 위치와 표시의 개념을 설명할 뿐 실제 부품을 찾을 수 있다고 보장하지 않는다. 사진을 쓰지 않기로 했으므로, 실차에서 찾는 데 충분한지는 실제 사용으로 확인해야 한다. Z Flip8과 실차 확인은 `NOT_RUN`이다.
