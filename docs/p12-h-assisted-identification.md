# P12-H — AI 보조 식별과 근거 비교

판정: **PROVISIONAL_AI_ASSISTED / 사람 최종 확인 필요**. 26장과 별도 IONIQ 5 사진 1장의 실제 픽셀을 확인했다. 기존 사진은 박스 없는 4장 단위 로컬 시트로 확인했고, 일부 캡 표기와 공식 도면 대조는 원본 크기로 추가 확인했다. 모든 사진의 작은 글자를 원본 해상도에서 읽었다는 뜻은 아니다. 후보는 정답이 아니며 공식 성능 개선을 주장하지 않는다.

기준은 PR #108 병합 main `7b781f2`, 작업 사본 `C:/dev/CarScope`다. 시작 당시 작업 사본은 변경 없는 `fix/avd-grant-not-before-wait` / `4c79cbf`였고 fetch 후 별도 브랜치를 만들었다. 해당 브랜치의 미병합 변경은 포함하지 않았다.

## 자료와 분석 방법

- 자동 후보: `C:/CarScope-External/p12-h/assisted-labels.json`. `humanReviewed: false`, 사진 SHA-256, 세트, 차량 메타데이터의 출처와 미확인 연식, 부품별 상태·좌표·시각 근거·자료 링크·사양 일치 한계·추가 자료 필요 여부를 기록했다.
- 비교 목록: 같은 폴더 `comparison-report.json`. 저장된 `p12-f/run1/answers.json`만 사용한다. 원본 파일과 현재 사람 검수 파일은 읽기만 했다.
- IONIQ 패키지 실재 확인: Downloads의 `carscope_ioniq5_labels_v2`에 원본 JPG, JSON/CSV 후보, 미리보기, README가 있다. 사진은 Michael Kramer의 Wikimedia 사진이며 새로 촬영한 사용자 소유 차량 사진으로 간주하지 않았다. 원본 1280×960, SHA-256 `cd64944d995756903d3cfd0b73a9685d8b8140055b736f4fed5e414978748508`, CC BY-SA 3.0이다. 원본·파생 화면은 Git 제외다.
- Roboflow 예측을 읽기 전에 박스 없는 사진에서 후보 좌표를 작성했다. 공식 자료를 대조한 뒤 Bolt 후보를 수정하고 나서 저장 예측과 비교했다. IONIQ 기존 패키지는 좌표 재작성 전에 읽었으므로 **기존 assistant 패키지에 대해 맹검은 아니다**. 좌표를 그대로 정답으로 복사하지 않았다.
- 로컬 `view_image`로 픽셀을 보고, 제조사 PDF는 내려받아 페이지를 렌더링해 직접 대조했다. 외부 비전 API·이미지 업로드·Roboflow 추론 요청은 사용하지 않았다. 파일명·초안만 보고 검수했다고 처리하지 않았다.
- 연식은 촬영일이나 파일명의 숫자로 확정하지 않았다. 차량명은 기존 출처 메타데이터이며 VIN 검증이 아니다. 다른 차종에 동일한 위치를 적용하지 않았다. 캡 색상만으로 부품이나 유체 계통을 확정하지 않았다.

## 모델과의 예비 비교

신뢰도 0.4 이상, IoU 0.5 이상으로 후보와 예측을 일대일 대응한다. 동일 클래스 대응을 우선한다. P12-G 계산식은 변경하지 않았고 후보 파일을 P12-G evaluator에 전달하지 않는다. **Precision/Recall은 계산하지 않는다.**

- 동일 클래스 탐지 성공 후보 **26건**, 미탐 후보 **42건**, 부품 혼동 후보 **4건**.
- 오탐 후보 **0건**: 부품 부재를 확정한 라벨이 없으므로 미대응 예측을 오탐으로 확정하지 않았다. 모델에 오탐이 없다는 뜻이 아니다.
- 판단 불가 **172개 목록 항목**. 후보 쪽과 미대응 예측 쪽 항목이 섞인 수이며 사진 수/부품 수/정답 수가 아니다. 여기에는 평가 대상 외 클래스도 포함된다. 숫자 클래스의 의미는 검증되지 않아 이름으로 변환하지 않았고, 그 박스와만 대응하는 후보도 판단 불가로 둔다.
- IONIQ는 저장 추론이 없어 비교 **NOT_RUN / NO_STORED_INFERENCE**. 새 추론을 호출하지 않았다.

캡/통 전체의 범위 차이, 거친 경계, 후보 누락, 두 AI의 공통 오류 때문에 이 수치는 정식 GT 평가가 아니다. 상세 목록은 외부 비교 JSON, 사진별 요약은 [증거 인덱스](evidence/p12-h/README.md)에 있다.

## 검수 도구

기존 레이아웃·색·그리기 도구를 유지했다. Codex 청록 파선, P12-F 흰 초안, Roboflow 점선, 사람이 편집하는 라벨을 별도 표시한다. 근거 링크와 문서 쪽수, 출처의 공식 여부, 사양 일치 한계, 추가 자료 필요 여부, 예비 비교를 부품별로 보여 준다. 현재 부품의 근거 부족 필터는 `EVIDENCE_SUPPORTED`가 아니거나 추가 자료가 필요한 사진을 남긴다.

**가져오기는 판정을 UNREVIEWED로 되돌리는 편집 초안만 만든다.** 검수자·시간·완료 여부는 만들지 않는다. 기존 P12-G 저장·완료 게이트가 그대로 적용된다. IONIQ는 별도 세트로 열고 브라우저에서 초안 편집할 수 있지만 P12-G 저장·평가 대상이 아니다. 현재 IONIQ 편집은 메모리에만 있고 이동 시 경고 후 사라진다. 별도 참고 세트의 영구 사람 검수 저장은 남은 과제다.

```powershell
Set-Location tools/vision-poc
npm run review
npm run assisted:report
# 다른 보조 파일: npm run review -- --assisted C:/CarScope-External/p12-h/assisted-labels.json
```

sidecar가 없으면 `NOT_AVAILABLE`, 잘못됐거나 사진 해시가 다르면 `BLOCKED`로 후보를 비활성화한다. 기존 P12-G 도구는 계속 쓸 수 있다. 원본 평가 자료의 무결성 문제는 기존처럼 서버 시작을 차단한다. 자동 후보 파일은 서버가 쓰지 않으며 배포/모바일/QR/WebXR에 포함하지 않는다.

## 남은 사람 확인

1. 차종별 연식·시장·파워트레인 확인과 정확히 적용되는 공식 자료 확보. 특히 모든 LCW 판정, 다중 냉각회로, 닫힌 퓨즈박스, 12V 표기가 안 읽히는 배터리.
2. 사진에서 실제로 보이는 경계와 캡/본체 범위, Bolt 외 차량의 추가 냉각 통 인스턴스. 후보가 없다는 것은 부품이 없다는 뜻이 아니다.
3. IONIQ의 두 냉각수 계통과 차종 사양. 가려진 배터리는 추가 사진 전까지 UNKNOWN 유지.
4. 기존 사람 검수 완료 1건은 이번 작업 전부터 존재했다. 자동 분석으로 사람 검수 완료 건수를 늘리지 않았다.

새 실행의 검증·스크린샷·파일 해시는 [증거 인덱스](evidence/p12-h/README.md)에 기록한다. Render 배포, Supabase 변경, API 키 읽기/노출, 이미지 Git 추가, PR 병합은 수행하지 않는다.
